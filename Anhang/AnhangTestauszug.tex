\subsection{Testauszug}
\label{app:Testauszug}

Der folgende Pytest-Auszug prüft den Zugriff auf die Benutzerverwaltung. Ein
Admin darf einen Benutzer anlegen. Anschließend wird geprüft, dass der neu
angelegte Benutzer mit der Rolle \Code{User} keinen Zugriff auf die
Benutzerverwaltung und das Anlegen weiterer Benutzer erhält.
